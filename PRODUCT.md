# Prototype Laboratory

## Platform

web

## Users

Game designers and engineers iterating a V57 TDD into a playable graybox before Unity production.

## Mode

Operate. The UI is a workbench: pick a TDD, generate a final prototype, play, chat-tune feel, sync the TDD.

## Brand voice

Calm, precise, no hype. Labels name actions. Empty states say what to do next.

## Purpose

Turn a Technical Design Document into a playable Three.js prototype that proves mechanics. The TDD remains the only product source of truth for Unity.

## Anti-references

Purple gradients. Glassmorphism. Inter/Roboto/Arial as primary UI fonts. Dashboard card grids in the first viewport. Lab jargon written into the TDD.
